Translation notes

  • All 44 scenes are live inline SVG; there are no raster assets.
  • SVG gradients, paths, circles, lines and ellipses correspond to Compose Canvas primitives. SVG screen blending and Gaussian blur are browser equivalents of Compose blend modes and bloom.
  • Compose FastOutSlowInEasing is represented by smoothstep in JavaScript; linear and the source sine ease use their source math.
  • The source random particle layouts are seeded here so comparisons remain stable across the four variants.
  • Global reduced motion freezes continuous drift and removes lightning flash while preserving a readable static weather state.
